# 🧁 Day 15 - HTML Task 15

## 🍰 Crumb & Bloom Bakery Website

A modern and visually attractive **Bakery Website** created using **HTML and Tailwind CSS**.

This task focuses on creating a complete bakery landing page with multiple sections, responsive layouts, bakery products, special offers, customer favorites and contact details.

---

## 📌 Project Overview

**Crumb & Bloom** is an artisan bakery website designed with a warm and elegant bakery theme.

The website includes attractive food images, smooth layouts, product sections, promotional content and a simple navigation menu.

The main goal of this task is to practice:

* HTML5 structure
* Tailwind CSS utility classes
* Responsive web design
* Grid and Flexbox layouts
* Image handling
* Navigation links
* Buttons and cards
* Section spacing and alignment
* Modern website UI design

---

## 🛠️ Technologies Used

* **HTML5**
* **Tailwind CSS**
* **Google Fonts**
* **Unsplash Images**

## ✨ Website Sections

### 1. 🏠 Hero Section

The hero section introduces the bakery with:

* Bakery name
* Main heading
* Short description
* Call-to-action buttons
* Fresh bakery image
* Today's special highlight
* Customer rating

---

### 2. 🥐 Daily Collection

Displays some of the bakery's signature products such as:

* Butter Croissant
* Midnight Cake
* Chunky Cookies

Each product contains:

* Product image
* Product name
* Short description
* Price

---

### 3. 🍰 Pick Your Happiness

A category section that presents different bakery choices:

* Pastries
* Cakes
* Cookies
* Coffee

This section uses simple icons and responsive cards.

---

### 4. 👩‍🍳 Our Story

Introduces the story behind **Crumb & Bloom Bakery**.

It contains:

* Bakery story
* Bakery image
* Establishment year
* Small-batch baking concept
* "Made with love" highlight

---

### 5. ☕ Weekend Special

A promotional section for the **Cozy Morning Box**.

It includes:

* Special offer badge
* Combo description
* Original price
* Discounted price
* Order button
* Coffee image

---

### 6. ❤️ Customer Favorites

Displays customer-favorite bakery items along with:

* Ratings
* Customer reviews
* Product names
* Short feedback

This gives the website a more realistic bakery experience.

---

### 7. 📍 Visit Us

The final section provides bakery information such as:

* Location
* Phone number
* Email
* Opening hours
* Menu button

A footer is also included with social media links and copyright information.

---

## 🎨 Design Features

* Warm bakery-inspired color palette
* Rounded image containers
* Modern typography
* Responsive grid layouts
* Hover effects
* Sticky navigation bar
* Call-to-action buttons
* Decorative elements
* Responsive design for different screen sizes
