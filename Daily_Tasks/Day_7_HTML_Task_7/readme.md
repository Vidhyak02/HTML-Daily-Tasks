# Day 7 – HTML Task 7

## 📌 Project Overview

This task is created as part of my **HTML Daily Tasks** practice.
In this task, I created a simple webpage using **HTML and CSS** in a single HTML file.

The webpage contains text content, an image, headings, and a button with basic CSS styling.

## 🎯 Objective

The main objective of this task is to practice:

* Basic HTML structure
* Headings and paragraphs
* Adding images using the `<img>` tag
* Creating buttons
* Applying CSS using the `<style>` tag
* Changing colors, fonts, spacing, and backgrounds
* Combining HTML and CSS in a single file

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
