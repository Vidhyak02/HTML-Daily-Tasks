# Day 9 – HTML SVG Task

## 📌 Overview

Day 9 of the **HTML Daily Tasks** focuses on **SVG (Scalable Vector Graphics)** and its implementation in HTML. This task demonstrates how vector-based graphics can be created and displayed directly within a web page using HTML and SVG elements.

## 🎯 Objective

The objective of this task is to understand the fundamentals of SVG and gain practical experience in creating scalable graphical elements using HTML.

## 💻 Technologies Used

* HTML5
* SVG (Scalable Vector Graphics)

## 🔹 Key Concepts Covered

* SVG structure and syntax
* SVG shapes and attributes
* Width, height, and viewBox
* SVG coordinate system
* Creating scalable vector graphics
* Integrating SVG with HTML
