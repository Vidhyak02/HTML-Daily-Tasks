# Day 3 – HTML Task 3

## 📌 Task Overview

This is **Day 3 – HTML Task 3** from the HTML Daily Tasks repository.

The main objective of this task is to practice creating a structured HTML webpage using basic HTML elements and understand how different HTML components are organized within a webpage.

## 🎯 Objectives

* Practice basic HTML structure.
* Use HTML elements effectively.
* Create a well-structured webpage.
* Understand headings, paragraphs, images, links, lists, and other HTML elements.

* Practice creating and viewing HTML output in a browser.
