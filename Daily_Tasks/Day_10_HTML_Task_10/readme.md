# Day 10 – HTML SVG Task

## 📌 Overview

Day 10 of the **HTML Daily Tasks** focuses on working with **SVG (Scalable Vector Graphics)** in HTML. This task provides hands-on practice in creating and structuring vector graphics using SVG elements and attributes.

## 🎯 Objective

The objective of this task is to strengthen the understanding of SVG and its integration with HTML for creating scalable, resolution-independent graphical content.

## 💻 Technologies Used

* HTML5
* SVG (Scalable Vector Graphics)

## 🔹 Concepts Covered

* SVG elements and structure
* SVG shapes and graphical components
* SVG attributes
* Width, height, and `viewBox`
* SVG coordinate system
* Creating scalable vector graphics
* Embedding SVG within HTML

## 📁 Project Structure

```text
Day_10_HTML_Task_10/
│
├── Day10.html
│
└── Output/

```

## 📝 Task Description

The `Day10.html` file demonstrates the implementation of SVG graphics using HTML. The task focuses on creating vector-based graphical elements while understanding the structure, dimensions, attributes, and coordinate system used by SVG.
