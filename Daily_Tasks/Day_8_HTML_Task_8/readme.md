# Day 8 – HTML Task 8: SVG

## 📌 Overview

This is **Day 8 of my HTML Daily Tasks**, focused on learning and implementing **SVG (Scalable Vector Graphics)** in HTML.

SVG is an XML-based format used to create vector graphics directly within a webpage. Unlike regular images, SVG graphics can be scaled to different sizes without losing quality.

## 🎯 Objective

The main objective of this task is to understand how SVG elements can be created and embedded directly into an HTML document.

## 🛠️ Technologies Used

* HTML5
* SVG (Scalable Vector Graphics)

## 📚 Concepts Covered

* Creating SVG elements using HTML
* Using SVG shapes and graphics
* Understanding SVG attributes
* Working with vector-based graphics
* Embedding SVG directly into an HTML webpage
* Creating scalable graphics without quality loss

## ✨ Features

* Simple SVG-based webpage
* Vector graphics created using HTML
* Scalable and resolution-independent graphics
* Clean and structured HTML implementation
* Demonstrates basic SVG functionality
