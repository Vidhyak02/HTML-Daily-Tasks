# Day 12 - HTML SVG Task

## 📌 Project Overview

This project is part of my **HTML Daily Tasks** series. In Day 12, the focus is on **SVG (Scalable Vector Graphics)** and how it can be used with HTML to create graphical elements directly on a webpage.

SVG is an XML-based vector graphics format that allows developers to create shapes, drawings, icons, and other graphical elements using HTML. Unlike normal image formats, SVG graphics can be scaled to different sizes without losing their quality.

This task helped me understand the basic structure of SVG and how different SVG elements can be used together to create visual content.

## ✨ Concepts Covered

### 1. SVG Element

The `<svg>` element acts as a container for SVG graphics. It defines the area where the graphical elements are created.

### 2. SVG Shapes

SVG provides different elements for creating basic shapes, such as:

* Rectangle
* Circle
* Ellipse
* Line
* Polygon
* Polyline

### 3. SVG Attributes

Different attributes are used to control the appearance and position of SVG elements.

Examples:

* `width`
* `height`
* `x`
* `y`
* `cx`
* `cy`
* `r`
* `fill`
* `stroke`
* `stroke-width`

### 4. Positioning

SVG elements can be positioned using coordinates. This makes it possible to arrange multiple shapes accurately inside the SVG area.

### 5. Styling SVG Elements

Attributes such as `fill`, `stroke`, and `stroke-width` can be used to customize the appearance of SVG elements.

## 💡 Why SVG?

SVG is useful in web development because:

* Graphics remain sharp at different sizes.
* SVG can be created directly using code.
* SVG elements can be styled and customized.
* SVG is suitable for responsive web designs.
* It can be used for icons, logos, illustrations, and diagrams.
* Simple SVG graphics can be lightweight.
