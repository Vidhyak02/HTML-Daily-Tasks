# 🌏 Explore India - Travel Destination

A simple and advanced **Travel Destination webpage built using HTML5 only**.

This project showcases popular Indian destinations, tourist attractions, activities, travel budgets, accommodation options, a travel checklist, and a travel enquiry form.

## 📌 Project Overview

**Explore India** is a travel website designed to provide useful information about different destinations in India.

The webpage includes:

* 🏠 Home section
* 📍 Popular destinations
* 🏛️ Must-visit places
* 🎯 Things to do
* 🔎 Destination information
* 💰 Estimated travel budget
* 🏨 Accommodation options
* 🎒 Travel checklist
* 📩 Travel enquiry form
* 📞 Contact information
