# 🌸 Day 16 - HTML Task 16

## 🌷 Lumière - Luxury Flower Boutique Website

A beautiful and modern **Luxury Flower Boutique Website** created using **HTML and Tailwind CSS**. This project focuses on an elegant, aesthetic design with attractive flower images, responsive layouts, and smooth hover effects.

---

## ✨ Project Preview

**Lumière** is a premium flower boutique website designed to showcase beautiful flower collections, floral stories, and elegant arrangements.

The website includes:

* 🌸 Beautiful Hero Section
* 🌷 Flower Collection
* 🖼️ Aesthetic Image Gallery
* 💐 Featured Flower Arrangements
* 🌿 About / Brand Story Section
* 📖 Flower Journal
* 💌 Newsletter Section
* 🔗 Footer with Navigation Links

---

## 🛠️ Technologies Used

* HTML5
* Tailwind CSS
* Google Fonts
* Unsplash Images
