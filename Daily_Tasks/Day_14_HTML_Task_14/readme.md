# Day 14 - HTML Task 14

## 📌 Task Overview

This task focuses on using **SVG (Scalable Vector Graphics)** in HTML to create and display vector-based graphics on a webpage.

## 🎯 Objective

* Understand the basic concept of SVG.
* Learn how to add SVG elements in an HTML page.
* Practice working with SVG graphics.
* Create a simple webpage using HTML and SVG.

## 🛠️ Technologies Used

* HTML5
* SVG

## 📂 Project Structure

```text
Day_14_HTML_Task_14/
│
├── Day_14.html
├── svg/
│
└── Output/
    └── output.png
```

## ✨ Features

* Uses HTML5 structure.
* Includes SVG graphics.
* Displays scalable vector elements.
* Simple and beginner-friendly implementation.
* SVG maintains its quality at different sizes.
