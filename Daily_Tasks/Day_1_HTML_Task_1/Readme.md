# Day 1 - HTML Task 1 🍰

## 📌 Project Title

**Vidz Bakery**

## 📖 Description

This is my **Day 1 HTML Task**, created as part of my daily HTML practice.

The project is a simple bakery webpage named **Vidz Bakery**. It introduces the bakery and highlights its benefits for college students, including study spots, budget-friendly snacks, and late-night cravings.

## 🛠️ Technologies Used

* HTML5

## ✨ HTML Tags Used

This task demonstrates the use of basic HTML tags and formatting elements, including:

* `<html>`
* `<head>`
* `<title>`
* `<body>`
* `<h2>`, `<h3>`, `<h4>`
* `<center>`
* `<u>`
* `<hr>`
* `<marquee>`
* `<p>`
* `<b>`
* `<strong>`
* `<mark>`
* `<del>`
* `<i>`
* `<ins>`
* `<br>`

## 🎯 Features

* Bakery title and welcome message
* Scrolling welcome text using `<marquee>`
* Text formatting using different HTML tags
* Highlighted content using `<mark>`
* Bakery description
* Information about:

  * Study spots
  * Budget-friendly bites
  * Late-night cravings

## 🖥️ Output

The webpage displays a simple bakery introduction page with formatted text and a welcoming bakery theme.
